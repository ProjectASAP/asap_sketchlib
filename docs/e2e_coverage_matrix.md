# E2E coverage matrix

This document maps the existing E2E suites. A family is an e2e_*.rs test file;
an algorithm, storage, path, or precision is a row.

The new Verified maximum error column is the upper bound established by a
successful test run. Most suites do not retain the exact observed maximum
(for example, 1.7%); that exact value is MISSING unless a row explicitly
reports it.

| Column | Meaning |
| --- | --- |
| Variant | Concrete implementation and configuration. |
| Input data | Distribution, element count, domain, seed, and ingestion form. |
| Family | Owning E2E suite. |
| Acceptance measurement | Exact comparison or numerical condition. 0 violations means every checked item met the condition; it does not mean every estimate had zero error. |
| Verified maximum error | The largest error the passing assertions prove is not exceeded, for the stated data/configuration. This is an upper bound, not the unrecorded exact maximum. |
| Bound or invariant | The error limit used by the test. |

In Count-Min rows, D is the number of distinct keys actually present in the
generated stream, and f_i is the exact frequency of the queried key.
